This is a Repo to hold the different projects being built for Alumni SpotLight Hackathon project for Hack-25

## Getting Started

This monorepo consists of two projects

### 1. Alumni Administration Portal

This is the portal which will be used by Alumni Offices of Universities to know about their student body. It has features like 

1) AlmaMatter Copilot - Ask question like 
   - show me alumni who recently changed employer in the last 24 hours
   - Show me alumni who moved to new cities recently
   - Show me student accomplishments

2) Planning an Alumni Event
3) Alumni Public Feed



### 2. Lite Social Networking Platform

 Lite version of linkedin, which allows you to post, change profile, comments etc
